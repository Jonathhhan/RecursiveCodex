# Genealogy and translation boundary

Recursive Codex originates in Jonathan Frank's book project *Zur Kritik der Organisation von Anschlussmöglichkeiten* and its Codex working methods.

The source project contributed operational patterns: recursive revision, montage-like comparison of executed variants, explicit provenance, relational consequence review, reversible change events, and an asymmetrical learning loop between a framework and Codex practice.

This repository generalizes only those procedures. It does not assert that every technical operation is an "actualization," that every project is a montage, or that the book's account of possibilities applies universally. Domain profiles must introduce their own terms and validity criteria. Similarity of workflow is not evidence for philosophical equivalence.

The book project remains the genealogical source; this repository is an independent technical descendant.
